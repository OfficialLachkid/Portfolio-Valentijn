Overview

During my internship at Domits, I worked on a hospitality platform focused on bookings, host tooling, integrations and direct booking flows. Besides building features myself as a fullstack developer, I operated in a lead developer role: reviewing pull requests, guiding engineers, leading morning and afternoon standups and standdowns, monitoring progress, unblocking issues, coordinating quality assurance, and helping manage merges from the development branch into main for production releases.

I also stayed in close contact with the CEO about delivery progress, priorities, and release readiness. This page collects the materials that explain both what I built and how I contributed to the engineering process around it.

Another part of that engineering process was improving how AI could be used in practice. This was not a separate task that was assigned to me: I set it up myself because I wanted working with AI to be more practical, easier for people to start using correctly, and easier to keep aligned with my own ongoing work. My aim was to reduce how much context had to be rebuilt at the start of each task and to make it easier for both me and other users to begin from a more reliable starting point. Using an Obsidian-based context vault, I created a workflow where durable product and engineering knowledge could be reused across chats, handoffs, feature work, and debugging instead of being lost in temporary conversations.
